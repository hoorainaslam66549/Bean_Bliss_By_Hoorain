# Bean Bliss — Final Dynamic Coffee Store Website

Modern minimalist design using **Oswald** headings and **Inter** body text.

## Included
- Home, About, Products, Cart, Checkout and Contact pages
- 20 coffee, drink, bakery and bean products with pictures
- Designed category cards and product cards
- Search and category filtering
- Add-to-cart with quantity controls and LocalStorage
- Designed payment gateway selection cards: Card, JazzCash and EasyPaisa
- Premium designed input, textarea, select and search boxes
- JavaScript form validation, toast notifications and confirmation modal
- Smooth fade/slide transitions between internal pages
- WhatsApp chat opens in a new tab
- Gmail compose opens in a new tab
- Google Maps embed
- Instagram, Facebook and LinkedIn links
- Responsive desktop/tablet/mobile design
